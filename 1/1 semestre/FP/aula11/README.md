# Aula 11

Nas aulas TP desta semana, fizemos uma breve introdução às funções:
`filter`, `map` e `reduce`.

São funções de ordem superior que se podem combinar para resolver uma classe
de problemas bastante comuns em diversas aplicações.
Elas permitem uma forma mais abstrata de lidar com tais problemas,
usando uma abordagem mais típica do paradigma de programação funcional.

Este tópico não será avaliado este ano.
Por isso, não apresentamos um guião de exercícios.
