--- 2. COSAS QUE SE INSTALARON (REQUISITOS) ---

Para que el código funcione en vuestras máquinas (VM o Nativas), debéis instalar lo siguiente:

1. Dependencias del Sistema (Necesarias para compilar librerías de Bluetooth):
   $ sudo apt update
   $ sudo apt install python3-pip libdbus-1-dev libglib2.0-dev -y

2. Librería Python del Proyecto (simplepyble):
   $ pip3 install simplepyble --break-system-packages

   (Nota: Usamos --break-system-packages porque en Kali/Ubuntu nuevos pip bloquea instalaciones globales, y esto es más rápido que configurar entornos virtuales por ahora).

--- 3. CÓMO PROBAR ---

Ejecutar desde la raíz del proyecto para ver si detecta vuestro dongle USB:
   $ python3 testnode.py

Si veis "[BLE] Hardware ativo: hci0", todo está correcto.
